# Assistant instructions

Follow [AGENTS.md](AGENTS.md).

Posnic credits human contributors only. Do not add this assistant or any other
AI tool to author, contributor, co-author, reviewer, maintainer, credit, DCO
sign-off, changelog, release-note, README, package metadata, issue, or
pull-request attribution.

Remove assistant signature footers before committing. If provenance is needed,
describe tool use as implementation context in the pull-request body, not as
contributor credit.
