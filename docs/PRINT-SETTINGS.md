# Printers and paper

Open **Core Settings → Print → Printers & paper** to choose where each document
prints. Save with **Save print settings**; receipt layout changes still use
**Save designs**.

- **Sales receipts:** choose a printer, paper and number of copies. Add another
  sales printer for an additional destination. Each destination uses its own
  receipt layout and copy count.
- **Invoices:** choose a separate printer and A4, A5 or US Letter paper. This row
  appears only while Invoices is enabled.
- **Quotations:** choose another printer, paper and copy count independently.
  This row appears only while Quotations is enabled.

For invoices and quotations, **Ask each time** opens the printer chooser.
Selecting a printer sends the document directly to that printer; **System
Default** explicitly uses the operating system's default. An unavailable named
printer produces an error instead of silently using another destination.

Desktop choices are stored on this computer and survive restarts. They do not
sync to another till. Sales settings use the same preferences as Hardware
Manager. Disabling a feature hides its controls and retains its saved choices.

In a browser, paper choices are saved in that browser. The browser print dialog
controls the printer and copies. The desktop app must be updated to use direct
document printing and the consolidated printer settings.
