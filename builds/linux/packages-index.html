Posnic package repository

Signed installers for the Posnic open source POS and billing software.

curl -fsSL https://packages.posnic.com/gpg.key \
  | sudo gpg --dearmor -o /usr/share/keyrings/posnic.gpg
echo "deb [signed-by=/usr/share/keyrings/posnic.gpg] https://packages.posnic.com/apt stable main" \
  | sudo tee /etc/apt/sources.list.d/posnic.list
sudo apt update && sudo apt install posnic

Source code and releases: github.com/Posnic/POS.
