# Posnic 1.9.0 — release notes draft

- Kitchen displays use space more efficiently: table details sit beside dishes, whole orders remain together, and shorter orders leave room for the next ticket beneath them. Portrait previews help configure vertical monitors.
- Compact quantity badges distinguish food still cooking, ready to collect and collected. Served quantities leave the active kitchen display. Cancelled items retain a clear cancellation notice.
- Kitchen Sound settings have clearer switches and recording readiness. Desktop staff can record, review and send a voice message. Supported touch kitchen screens can replay recordings attached to an order.
- Additions to an existing kitchen order are labelled **Running Order**. Captain-entered preparation amounts remain visible on kitchen tickets and displays.
- Hardware Manager settings and previews are better organised. Receipt preview timestamps omit seconds, and refresh controls follow the selected theme.
- Browser authorization returns focus to Posnic and provides an **Open Posnic** fallback button.
- Includes printing recovery, import validation, customer balance and access-control fixes accumulated since the previous public release.
- The mobile POS API supports resumable catalogue downloads, receipt delivery evidence and authorised weighed quantities. Matching mobile client support is required for client-facing features.
